Third release candidate of Orbyn Forge 0.1.0, for testing installs and upgrades on staging servers.

## Highlights since 0.1.0-rc-01

- **Analytics in its own process.** `forge-analytics-worker` runs next to `forge-server`, which starts and supervises it. Nodes upload node history, container output and application logs to it over mutual TLS on **TCP 55132**: allow that port from your nodes.
- **DuckDB is the default analytics engine.** No download and no server; it holds about 100 nodes with moderate logging. Choose `embedded` (chDB) or a ClickHouse server for heavy load.
- **Signed installs.** `get-forge.sh` and `get-forge.ps1` download a release, check `SHA256SUMS.sig` against the pinned Orbyn Forge key and the package checksum, and only then run the installer. `install.sh --uninstall` (and `--purge`) removes Forge.
- **Agent updates** go to the version named in the agent folder's `MANIFEST.json`, and rollouts skip nodes that cannot take an update instead of stopping.
- **Version order:** a release candidate sorts below its final release, so `0.1.0` will be offered to installs on `0.1.0-rc-03`.
- Node removal, the Docker Engine API over mutual TLS, container shells through the agent, and many fixes.

Upgrading an rc-01 install: read the [upgrade notes](https://forge.orbyntech.com/docs/reference/upgrade-notes/) first.
