# Security policy

## Reporting a vulnerability

**Do not open a public issue for a security problem.**

Report it privately through GitHub:
**Security** → **Report a vulnerability** on
[`mr-aybee/forge`](https://github.com/mr-aybee/forge/security/advisories/new).

Include:
- the affected version or commit;
- the steps to reproduce;
- the impact you expect.

We aim to acknowledge reports within a few days and will agree a disclosure
date with you.

## Supported versions

Security fixes go into the latest release. Upgrade with `forge update` or
`get-forge.sh`.
